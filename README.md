# Andrenic

Sitio web responsivo de Andrenic, marca colombiana de calzado, tocas, uniformes y accesorios para profesionales de la salud.

Proyecto de la asignatura Ingeniería Web I, Universidad Manuela Beltrán.

## Estructura

```
index.html
css/style.css
js/main.js
img/
```

## Tecnologías

HTML5, CSS3 (Flexbox, Grid y Media Queries) y JavaScript.

## Cómo ejecutarlo

Abrir el archivo `index.html` en un navegador. No requiere instalación.
